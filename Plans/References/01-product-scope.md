# 产品与范围

## 产品定位

用户输入房间与空调方案，在 Mac 上查看稳定运行后的气流和温度分布，理解各位置的舒适差异，比较配置与运行成本，得到可执行建议。
核心价值链：空间模型 → 物理计算 → 位置级评价 → 成本取舍 → 证据报告。

## 用户与首个切面

| 用户 | 场景 | 决策 | 模板差异 |
|---|---|---|---|
| 个人 / 家庭 | 卧室、客厅 | 风向、设定、安装位置 | 床位、睡眠活动、夜间时间表 |
| 企业 | 小办公室、会议室 | 工位舒适、容量、运行费 | 设备热源、工作日、人员变化 |
| 学校 | 单间教室 | 前后排差异、配置、新风 | 高占用、座位网格、上课时间表 |
| 组织 | 办事空间 | 预算、留档、配置依据 | 评价档案、报告与部署要求 |

首版选有现场数据的小办公室或教室。一套底座、多种模板；首先支持一类分体空调。儿童人群舒适适用性需要独立评价。

## 比赛范围

Must：矩形单房间、门窗、盒体家具、座位、一种空调、位置 / 风量 / 风向 / 设定、基准加两个候选、代表日 L1、代表工况稳态 L2、座位评价、费用、结果状态、基础报告。
Should：少量位置候选、多台同类空调、简化 CO2、现场数据、敏感性、扫描导入。
Later：任意扫描几何自动网格、吊扇模型、多房间、代理模型、中央空调、瞬态降温、动态耦合、实时控制与全年核证。

## 主要故事与验收

1. 用户创建房间并给未知物理参数选择有来源的预设；可查看假设列表。
2. 用户放置空调与座位；不合法位置不能提交计算。
3. 用户运行基准；显示质量状态和位置指标，缺失值显示未知。
4. 用户复制方案改变参数；旧结果标记待重算；完成任务归属正确。
5. 用户比较同一天、同人数、同时段的舒适 / 电耗 / 成本；可选预算与舒适约束。
6. 用户输出建议卡；每条定量结论可追溯到运行与参数。

## 产品指标

记录用户建模耗时、任务成功率、方案计算耗时、有效座位覆盖、达标座位比例、最差位置、代表日电耗和费用。
比赛不给未经测量的性能或节能百分比承诺。模型指标与实测满意度分开。
容量合格和气流组织合格是两道检查；无可行方案时解释原因，不强行推荐。
