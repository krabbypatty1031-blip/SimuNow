# 验证计划

## 分层证据

| 层次 | 验证 | 必须保留 |
|---|---|---|
| 工程 | 包测试、双平台编译、启动与导航 | 版本、命令、结果 |
| 协议 | Swift/Python round-trip、版本、序列、缺失/损坏 | 输入夹具与错误行为 |
| 数值正确性 | 网格、单位、质量/能量、收敛 | mesh/solver hash、日志、监测 |
| 模型验证 | 公开基准、三网格、独立实测 | 来源、误差、适用范围 |
| 决策 | 相同口径、可行性、敏感性 | 候选与推荐依据 |
| 效果核证 | 改造前后、天气/占用修正 | 数据时段、方法与不确定性 |

## 具体检查

- Codable 与 schema 一致；未知枚举、版本、无单位与无效尺寸有明确处理。
- 本地任务 stdout 分段/乱序/重复、取消、失败、旧任务完成不覆盖新输入。
- 两端深浅色、动态字号、横竖屏、VoiceOver、空状态与错误。
- 同时段基准/候选共享单位、色标、相机；指标范围一致。
- 守恒检查定义分母、绝对误差与边界能量项；热源、壁面、送回风同口径。
- 残差与温度/速度监测同时稳定；低残差不能代替守恒或现实验证。
- 座位样点在流体域，mask 排除实体，近零速度采用绝对误差辅助。
- PMV 方法、MRT/RH/met/clo、空气速度处理与模型范围有记录。
- 代表日不输出年度节能；成本有报价；“未配置”无成功结果。

## 物理案例顺序

公开浮力基准 → 室内非等温射流 → 简化真实房间 → 现场独立验证。记录各案例对本产品证明的范围。
三网格比较关键位置、区域统计、推荐排序。阈值依实际误差与决策敏感性制定；初始质量1%/能量5%门槛仅为工程目标。
现场优先温度、风速、送风条件、功率，再增加湿度/CO2。仪表、时间、位置、占用、门窗与设备状态成套记录。

## 完成规则

同一阶段关键检查通过后不反复扩大无关测试。改动、失败或未解决风险才触发追加验证。
编译、实际运行与物理验证分开记录。当前记录见 [verification.md](../../../Delivery/verification.md)，未来运行证据索引到匿名 run/fixture。
