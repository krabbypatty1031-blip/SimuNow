# 交互与视觉设计

## 首次使用与日常使用

首次：选已有模板/打开项目 → 确认尺寸 → 放置空调和关注位置 → 查看三维房间与风向。高级面板保留 P2 物理字段，不要求用户先填写完整围护、天气和设备性能。

日常：打开保存的房间 → 调整风向/风档或切换候选 → 看路径和遮挡 → 阅读建议依据 → 保存。首版只做设置建议，不自动控制真实空调。

几何更新立即显示；本地分析在短暂防抖后执行，可随新编辑取消。目标防抖 150–300 ms，N3 实测确定。计算结果到达前保留旧图并标记过期，不能让旧箭头看起来对应新设置。

## 工作区

| 区域 | Mac / iPad | iPhone |
|---|---|---|
| 模型 | 中央三维/俯视切换 | 单页视口，属性在 sheet |
| 方案 | 基准与候选列表 | 方案选择器和独立比较页 |
| 属性 | inspector 中常用项先显示 | 尺寸、位置、风向、风档的紧凑表单 |
| 分析依据 | 方法、假设、缺项可展开 | 同样可达的详情页 |
| 历史 | 后台记录，不迫使用户管理任务队列 | 当前预览与取消即可 |

三维最少支持旋转/缩放、俯视/等轴、重置和选中聚焦；拖拽移动作为后续增强。已有数值编辑与二维点击继续可用。天花板隐藏、朝向一侧墙体隐藏或透明仅影响观看，障碍规则仍使用完整模型。

空调机身没有已定义几何尺寸时使用中性的符号，不伪造实物大小。门窗显示于对应墙面；关注位置沿用座位/采样点 ID，不为了渲染再造实体身份。

## 图层与文字

| 图层 | 可显示 | 必须解释 |
|---|---|---|
| 房间 | 家具、门窗、空调标记、关注点 | 尺寸单位和简化几何 |
| 气流预览 | 方向箭头、假设扩散范围、路径、可选动画 | “规则预览”；动画速度仅用于展示 |
| 路径提醒 | 路径相交、前方遮挡、未模拟区域 | 规则条目和假设，不叫 PMV 或通风达标 |
| 热量/费用 | 汇总卡、同口径情景范围 | 方法、输入来源、时段和缺失值 |
| 测量 | 后续导入的真实读数 | 时间、仪表、位置，和预览分开 |

不在无空间温度解时铺设红蓝温度场。无量纲路径强度不用 m/s 色标；风档低/中/高默认只是设置类别。风量未知不通过颜色深浅暗示真实流量。

点击一个关注点，先给“在假设路径内/被遮挡/没有足够信息”，再展示使用了哪些几何和规则。未知不是零，也不是通过。方法与依据用常用词，技术版本放在详情或报告证据中。

## 比较与建议

基准加两个候选共用相机、扩散档案和评价规则；不同假设不能混成单一改善百分比。建议优先解释“将当前直吹路径移开关注点”“清理前方遮挡”“需要补充实际功率”，给用户可执行调整与条件。

改风向时用电卡保持原依据，不自动降功率。范围重叠或输入不同则显示难以判断；不提供无来源的最优设定、舒适得分或节能排名。

## 可访问性与失败行为

三维中的每个可操作对象都有列表/表单替代。VoiceOver 可读对象名称、设置、方法和结果；不要求读屏用户选择粒子。Reduce Motion 使用静态箭头/路径。深浅色、动态字号、触控目标、键盘、横竖屏和二维回退列入验收。

没有房间时复用 P2 创建入口；没有风口只显示几何和补充入口；未支持的对象保留并解释；任务取消、文件损坏和能力不足可恢复。未实现能力继续用明确空状态。
