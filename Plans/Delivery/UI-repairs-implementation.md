## 自动检查与限制

- 39 项 Python 回归通过；项目模型与原本地分析 schema 生成检查通过，无物理输入契约漂移。
- 33 份完整变更/新增 Swift 文件及 1 处新增比较测试片段通过 tree-sitter-swift 语法树检查；该测试所在旧文件含解析器不支持的既有 async 语法，原文未修改。它不检查 Swift 类型、SwiftUI API availability 或布局，不能代替编译。
- 新增 Swift 回归覆盖时钟边界/未完成输入、字段名称语义、相机平移、显式比较基准、可选历史展示信息不修改原分析证据。测试源码已加入，当前环境没有 `swift`，尚未执行。
- 历史时间为结果加入项目的时间，不是求解启动时间。旧记录缺少时间时如实说明；未知/未来展示版本忽略，原文件保留，分析附件仍严格验证。
- 简化位置编辑不提供任意旋转家具；门窗不提供未建模门扇方向；报价没有对象关联时不伪造关联。
- 自动定位使用当前事务中的字段路径与 UUID。结构损坏、未知扩展、无有效父对象的关联异常给出恢复说明；不能推定单一字段的整体几何/覆盖错误保留整体说明。重复时间段使用所属实体与区间序号定位；焦点和读屏的实际行为仍需平台核验。
