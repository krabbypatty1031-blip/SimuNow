# P5：方案、成本与比赛交付

## 目标与前置

将有效计算变成用户可选择的配置方案。前置 L1 能耗、L2 空间结果、统一质量与运行身份。

## 功能、设计与技术

基准复制、候选枚举、舒适/预算约束、运行与改造成本、同口径对比、建议卡、基础 PDF。
Python / SciPy 枚举与过滤；Swift Charts；报告模块使用共享结果快照。PDF renderer 在 P5 决定并锁定，不从 View 重新生成数值。

## 工作项

| ID | 工作 | 验收 |
|---|---|---|
| P5-01 | 候选变量、可改项、约束与筛选 | L0/L1 只做对应范围筛选 |
| P5-02 | L2 可行性、达标比例、最差座位 | 无可行方案有解释 |
| P5-03 | 电价/报价/币种与费用分层 | 缺数据待报价，收益口径清楚 |
| P5-04 | 三类建议、同视角色标、PDF 证据 | 每结论有 run ID/方法/假设 |
| P5-05 | 离线演示、失败路径、打包检查 | 固定输入链路复现 |

## 推荐规则

先容量与约束，再舒适，再能耗与费用；保持多目标指标可见。风向改善节电需要新运行设定或控制模型的依据。
稳健性先对最关键1–2假设做扰动；排序翻转时标记条件。没有年度情景不出全年费用或回收期。
报告写代表日/工况、数值版本、quality、假设、待补测与建议，不声称合规检定已完成。

## 验收与降级

一个基准+两个候选有有效比较、建议和基础报告；改变输入后报告来源仍是固定 run。
复杂 Pareto 先退到可解释的三方案表；PDF 布局复杂时完成清晰基础版。界面不得宣称全部设计空间全局最优。
