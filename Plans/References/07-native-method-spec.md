# Swift 本地方法规格

本页记录首版方法约定；N1基座及N3规则实现已整合，实际接口与未验限制见[N3交接](../Delivery/N3-implementation.md)。N4功率/费用/显热算法仍待实施。具体任务/验收见[N3](../Phases/N3-local-airflow-preview.md)、[N4](../Phases/N4-thermal-estimates-and-comparison.md)和[案例](11-native-acceptance-cases.md)。目的为可复现的方向/遮挡线索和有依据的聚合估算。规则参数是内部展示选择，未经测量或文献校准的数值不能当作现实射流系数。

## 1. 输入投影和适用范围

从 ScenarioInputSnapshot 构造方法专用输入，保留 room/device/port/seat ID、几何、源值和单位。首期支持一个矩形房间、盒体障碍、单台分体空调、静态风向、送风口与关注点。

预览最低输入：有效房间、送风口位置、指向流体内部的非零方向。已有设备的 ports 可能为空，需用户明确建立一个等效出风口，不从设备位置自动推断真实开口。机身没有尺寸，显示中性符号，碰撞只针对房间与有定义尺寸的家具。

门窗在首期可视化为语义开口，但默认预览把房间当作封闭查看域；有开启门窗时显示“跨开口气流未模拟”，不推导室外进出。多设备/复杂几何只查看几何，气流分析明确 unsupported，不默默计算其中一台。

就绪度分 roomView、airflowPreview、powerEstimate、steadyHeatBalance，分别列缺项。保存草稿仍走 P2 完整性规则；不能用预览成功改变原严格物理校验结果。

## 2. 无量纲方向预览

出风方向d先通过项目单位向量校验，算法仅为浮点误差再次归一化；非法导入向量必须修复，不能自动修正。点 p 相对风口 o 的轴向距离 s = dot(p-o,d)，横向距离 r = length((p-o)-s*d)。仅在 0 ≤ s ≤ L 且 r 位于假设扩散宽度 b(s) 内生成预览。

首个内部档案`simunow.preview.genericCone` version1采用b0=0.05m、半角12°、L=房间对角线；这些都是用户需明确接受的展示假设，不是现实射流系数/射程/风口面积。允许角度1…45°，b0>0，L≤diag；变更实际值/版本使对应hash失效。

采用`b(s)=b0+k*s`、`k=tan(halfAngle)`、`q=r/b(s)`；在0≤s≤L、q≤1流体域内，direction=normalize(d+k*rvec/b(s))，strength=max(0,1-q²)/(1+s/L)²，单位1。中心轴direction=d，边缘强度0。无效位置返回notEvaluated/无场样本，不能当0风速。

无设备风档映射时首期UI写“预览密度”低/中/高=16/32/64条路径，只改显示采样；不改变目标关系、不能对应具体m³/s、m/s或电功率。静态无量纲方向和强度不作为守恒的空气速度场。禁止通过简单叠加或回风吸引补出看似完整循环。

如后续有独立来源的出口流量与面积，可检查 `U0 = volumeFlow / area`，但该出口平均速度不等于各座位速度；具体射流衰减仍需 N6-02 校准/适用性证据后才能输出单位速度。

## 3. 路径、障碍和显示

固定UInt32 seed默认1；中心路径第一条，其余截面采样使用Halton base2/base3、非中心i从1起、index以UInt64(i)+UInt64(seed)避免溢出、r0=b0√u、phi=2πv。正交helper选与d最不平行正轴、tie X→Y→Z。纯向量场公式要求刚体等变；含AABB碰撞/关系只测试保持轴对齐的变换，任意旋转后的OBB不在首版支持范围。截面helper使用世界轴，任意旋转不要求离轴pathID点列一一等变。每次步进沿规则方向场推进，用线段-墙面/盒体相交求最早碰撞，不只检查终点，防止一步穿过薄家具。

位于墙面上的合法风口，沿已确认内向d偏移epsilon=clamp(diag×1e-7,1e-6,1e-4)m，避免零距离自碰撞；内部合法源不移动，偏移后不可进入家具。碰撞或越域立即停止；低强度、零方向、长度/步数上限同样结束。遮挡后标未模拟，不假装气流消失代表物理吸收，也不增加无依据的弹性反射、壁面滑行或绕障涡流。

内部初始预算：单房间/单设备/单supply、128boxes、512targets、64条路径×128段；强度终止阈值0.01；轴向步长L/maxSegments。段碰撞使用slab最早交点并裁到hit，同t按UUID稳定排序。数值/预算先在N3-06测试后锁定，变更须升profile/config版本。渲染用合并的线/实例或有限标记，避免为每帧粒子创建 Entity。先静态路径，再按已生成路径播放动画；通用 ParticleEmitter 若无法满足障碍终止则不使用。

动画为展示时钟，可暂停/减速/关闭；不标真实飞行秒数。减少动态效果时使用静态路径与对象列表。任何网格采样只是显示缓存，不是 CFD mesh。

## 4. 关注点与规则结果

对每个有效关注点，根据前向范围、横向档案和风口到点的遮挡段返回：`intersectsAssumedPath`、`occluded`、`outsideAssumedPath` 或 `notEvaluated(reason)`。保存 RuleID/version、关注点 ID、采用档案和几何证据。

“未在路径内”不代表无风；“遮挡”不代表不舒适；“路径相交”不提供局部吹风风险。首版可输出路径关系数量，不称为舒适达标座位比例。未知或实体内采样点不得算作无风/零速度。

建议仅根据这些关系生成条件语句；将风向移开关注点可能减少假设直吹路径，但没有未测环境下的舒适改善保证。

## 5. 用电与电费

首期方法：按时间片积分 `E_kWh = Σ(P_W * duration_seconds) / 3,600,000`。P 是实测时段平均功率、用户显式情景或有来源的功率范围。额定输入功率只计算“按额定功率连续运行”的情景，不自动补启停率。

首版采用fixed24HourReference的0…1440分钟半开区间，不声称是夏令时实际账单日；跨午夜显式拆段。请求窗口必须被功率完整覆盖，停机为明确known0；缺片段时完整电量missing，已知小计单列覆盖范围。P2 schedule fraction不是自动启停率。

电费按功率/费率/请求窗口边界并集逐片计算。校验重叠/空缺、非负有限功率、币种、费率来源；单币种费用采用明确Decimal转换/累计，最终展示才格式化，不把缺项填0。制冷量是热功率，不能当作电功率。风向不改变该方法输入投影，因此同功率时长下不生成角度节电。

区间采用来源中的功率下/上界积分，或多个明确情景分别计算；不赋予概率。时间片边界与费率边界统一分割，避免跨价段计费错误。

## 6. 稳态显热估算（Should）

首版explicitAggregateUA模式，UA只接显式合计值/范围与来源，不自动从P2表面U及房间面积推断。conditionMinute确定代表时段；Tin来自设定点时需用户明确采用为条件。

在明确Tin、Tout、有效UA、室外空气交换、内部显热和太阳得热时：

`Q_required = UA*(Tout-Tin) + rho*cp*Vdot_outdoor*(Tout-Tin) + Q_internal_sensible + Q_solar`。

UA 单位 W/K；Vdot_outdoor为新风+渗风之和，单位m³/s；各Q为W。人员/设备显热与太阳热分别计一次；辐射分量在集总稳态总显热口径中说明，不另重复添加到空气热源。循环送回风不加入 Vdot_outdoor。缺项必须停用相关估算，ρ/cp 若使用常数需记录温度范围和来源。

制冷显负荷用 max(0,Q_required)，但保留带符号热收支以解释无制冷需求；不能据此承诺制冷后室温已达 Tin。总制冷能力与显负荷比较必须有显热能力或 SHR 依据，未知时仅报负荷、不判设备合格。

首版不求湿度/潜热，不用显热负荷直接除无来源 COP 给耗电。围护/太阳/渗风未知时可展示用户明确接受的子集情景，记录excludedTerms；重要项被排除时禁止完整容量通过结论，不隐藏为完整房间负荷。

范围比较首版最多2个区间输入、4个端点组合加名义情景，输出情景包络而非概率；重叠/排序翻转不可标最佳。不同方法/version/时段/币种/背景工况及过期结果不得给改善百分比，零基准百分比不可定义。

## 7. 动态与物理扩展（Later）

RC 选项采用 `Ceff*dT/dt = thermalBalance - Q_HVAC`，必须另有 Ceff、设备/控制和时间步验证，不能用空气热容量默认代替墙体家具蓄热。校准与验证数据分开，平均室温仍不是位置温度。详见 N6-03。

原生网格求解在 N6-04 独立做 go/no-go：边界条件、不可压质量投影、温度对流扩散/浮力、稳定步长、空间/时间分辨率、公开基准与内存预算都需证明。Swift/Accelerate 是候选实现方式，Metal 仅在测量证明瓶颈时引入；不得借“Stable Fluids”或视觉稳定性宣称室内预测已经验证。

## 8. 最小可复现验证

| 方法 | 解析/几何案例 | 失败与反例 |
|---|---|---|
| 方向预览 | 空盒中心轴；旋转/平移等变；同 seed 同路径 | 零方向、背向房间、非有限数 |
| 碰撞 | 薄家具横穿路径、掠过边界、起点在实体内 | 步长变化不得跨实体；碰撞后不继续 |
| 规则 | 路径内/外/遮挡三点，换角度后标签变化 | unknown 不显示“通过”，不会产生 PMV/T |
| 用电 | 1000 W × 2 h = 2 kWh | 缺功率、重叠/跨费率、币种不一致 |
| 显热 | UA=100 W/K，温差10 K且其他项明确为零，得到1000 W | 未知不是零；循环风不能变成室外换气 |
| 身份 | 新编辑取消旧任务、缓存命中属于新请求 | 错 run/scenario/hash 不覆盖当前 |

这些检查证明实现符合方法，不证明真实房间精度。现实验证从 N6 的独立测量开始，保留误差、适用条件和未覆盖物理。
