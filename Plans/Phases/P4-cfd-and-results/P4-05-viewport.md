# P4-05 视口、场格式、切片

**Files:** `SimuVisualization` 房间几何 + 场适配；`SimulationViewport` 替换空状态  
**依赖:** P4-01 几何；场叠加依赖 P4-03  
**不做:** 无 L2 结果时画示意彩虹场；体积渲染冒充；粒子动画当降温时间

**约束:** 显示 Y-up ↔ 计算 Z-up 走现有 `CoordinateMapping`。无效掩码中性色。两方案色标后由 P4-06 共用。

### P4-05a 房间几何

- [ ] 盒子、窗、送回风、座位可见
- [ ] 模型不完整仍显示空状态，不画假房间

### P4-05b 场文件

- [ ] float 格式、endian、轴序、单位、掩码、哈希写清
- [ ] 墙/家具内部不参与统计

### P4-05c 切片

- [ ] 有质量通过的场才叠坐姿高度温度切片
- [ ] 色标带 °C；无场不填色
