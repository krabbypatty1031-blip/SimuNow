# P7：优化、批量与产品加固

## 目标与前置

使配置决策可复用、可批量、可部署。前置真实案例、稳定参数空间与误差数据；目标赛后第5–8周，性能与范围以验证为准。

## 功能、设计与技术

多台同类空调、设备数据、位置/容量/数量候选、Pareto、稳健搜索、房间绑定代理、模板差异覆盖、远程执行器、签名与试点。
SciPy、scikit-learn、可选 pymoo、私有节点、Apple 签名/公证。引入 PyTorch 以样本规模与模型收益为依据。

## 工作项

| ID | 工作 | 验收 |
|---|---|---|
| P7-01 | 多设备与离散配置、真实报价 | 容量/流量/成本随方案一致更新 |
| P7-02 | 多目标与扰动复核 | 候选可行、排序稳定性可见 |
| P7-03 | CFD 采样、代理留出、范围与模型绑定 | 误差明确、越界回退、最终 L2 |
| P7-04 | 模板/差异覆盖、批量与远程 | 显著差异补算、排队取消可靠 |
| P7-05 | 沙盒/helper/运行时、签名、试点 | 新机器部署、前后效果证据 |

## 产品质量

代理先标量后全场；不能将插值指标展示为精算空间场。模板复用检查几何/设备/占用适用包络。
远程能力用户显式配置，最小数据包、加密、认证、资源限额、删除策略与机构节点部署；iOS 与 Mac 使用统一结果格式。
全年天气与使用时间表完成后才增加年费用；中央系统/瞬态/动态耦合按新的验证工作包推进。

## 验收与降级

一处真实办公室/学校试点，用户能复用模板、理解假设、获得可核验建议。性能以目标设备实测记录。
代理误差不足以支持决策时保持直接枚举/CFD；批量复杂时先单房间稳定版；发布仅在用户授权时执行。
