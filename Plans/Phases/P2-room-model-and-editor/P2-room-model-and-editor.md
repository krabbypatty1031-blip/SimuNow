# P2：房间数据与编辑

## 目标与前置

让用户生成可校验的房间/设备/座位输入。前置 P0；可与 P1 并行，字段按共同协议冻结。

## 功能、设计与技术

矩形创建向导、门窗、盒体家具、空调和座位放置、使用条件、模板、保存导入。
Swift Codable、Pydantic/JSON schema（接入时锁版本）、SwiftUI Form、RealityKit/渲染适配、平台文件选择与安全书签。
Mac 属性面板与 iOS 详情表单复用字段；先数值编辑与俯视放置，再增强 3D 手柄。

## 工作项

| ID | 工作 | 验收 |
|---|---|---|
| P2-01 | draft 扩展为完整项目，分几何/使用/HVAC | schema、迁移、双端 round-trip |
| P2-02 | 向导、尺寸、门窗、朝向、参数来源 | 有单位，未知与假设可查看 |
| P2-03 | 家具/设备/座位编辑，坐标集中转换 | 不穿墙，方向与身份正确 |
| P2-04 | 项目包原子保存、导入、损坏与版本处理 | 关闭/重开输入一致 |
| P2-05 | 办公/教室模板、基准方案、编辑快照 | 模板参数有出处与可覆盖项 |

## 设计细节

风量、面积和风速相互校验；设定与送风分开。座位 ID 稳定，人物与采样点分开。
项目编辑支持撤销的范围在本阶段决定；保存不得包含本机绝对私有路径。只在表单完整时开放计算操作。

## 验收与降级

输出能进入 P1 管线，错误定位到具体字段；Mac 和 iOS 能浏览同一输入。保存/导入有实际行为后再显示可用按钮。
拖拽复杂时保留数值编辑与俯视点击，任意扫描几何放 P6；不延后统一坐标校验。
