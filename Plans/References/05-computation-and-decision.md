# 物理计算与决策

## 四级模型

| 层级 | 输入与技术 | 输出与边界 |
|---|---|---|
| L0 | Python / NumPy；热平衡、集总污染物、射流量级 | 总负荷与平均状态；空间结论仍需 L2 |
| L1 | EnergyPlus；天气、围护、人员与设备、控制 | 代表日冷负荷、电耗、表面温度；性能曲线有来源 |
| L2 | 固定 Linux OpenFOAM；稳态 RANS、浮力、热源 | U、T、湍流、座位指标；瞬态与湿度范围另定义 |
| L3 | 房间绑定采样、scikit-learn、留出验证 | 范围内标量指标；最终候选 L2 复核 |

P1 验证后锁定 OpenFOAM 发行分支、求解器、湍流与近壁面模型。不要混用 Foundation/OpenCFD 教程配置。Boussinesq 条件、网格与壁面处理应有一致依据。

## L1 与设备

比赛可用 Ideal Loads 求负荷，加有效 COP 和辅机功耗估算；必须标为等效模型。理想负荷热量不是设备电耗，容量不足不能由无限供冷掩盖。
有设备曲线时用显式 HVAC 模型，考虑室外条件、部分负荷、显潜热和控制。额定点信息不能代替全年性能。
送风状态由设备模型或实测生成；仅有假设时记录范围，并做敏感性。室内机位置改变不能自动产生固定节电系数。

## CFD 管线

输入校验 → 简化几何 → 网格 → checkMesh → 边界转换 → 求解 → 守恒/收敛 → 座位采样 → 场重采样。
首版：矩形室内流体域、家具盒体、人体简化热源、等效出风口、真实回风、新风单独处理。风口/人体/剪切区局部加密。
墙面使用 L1 表面温度或热流；每个面只选择一致边界，不同时强制互相矛盾的条件。
人体显热分对流/辐射；L1/L2 热源口径一致。稳态对应运行稳定工况，不提供降温时间。
若改变风向后允许提高设定仍舒适，通过新的 L1 工况计算节电；后续回传传感点和回风偏差修正控制。

## 热舒适

座位附近多点采样空气温度、速度、必要湍流量；MRT 由表面辐射条件近似，RH 使用模型/实测/假设来源。
pythermalcomfort 按选定方法处理 met、clo、相对速度与适用范围；不要关闭输入限制来伪装可评价。吹风风险的湍流估计在低速度处需要稳定处理与模型范围检查。
记录 PMV/PPD、局部吹风、垂直温差与区域温差；“达标座位比例”是模型判据的覆盖率，非实测满意率。
学校儿童、睡眠等场景需要适用性审查，不能默认成人办公模型适用于所有人群。

## CO2 与通风

先完成集总动态质量平衡，明确人数排放、室外浓度与新风/渗风。无室外交換且持续排放时不存在有限稳态。
CFD 标量源与循环回风浓度要一致；不能将回风当持续清除污染物的外排。CO2 只是通风线索，不能代表完整空气质量。
标准档案按地区和统计时间配置；瞬时/稳态值不直接作为 8 小时平均检定结论。

## 成本与推荐

电费 = sum(电功率 × 时间 × 电价)；记录币种、费率来源和时间。辅机功耗按设备性能定义避免重复计入。
改造费用来自可追溯报价；代表日不直接外推年度。回收期需要有效年净收益，非正收益/未知输入显示不可计算。
先 L0/L1 筛选容量、能耗、预算，再 L2 检查位置级舒适；没有空间结果时不能声称候选满足所有座位约束。
保留运行调整、舒适改善、配置改造三类可行候选；同天气/人数/时间/成本口径比较。无可行方案解释约束，不制造最优。
枚举 3×3×3（设定/风档/角度）作为起点；位置、数量作为外层离散变量。P7 再引入 Pareto/NSGA-II、稳健性与代理。

## 质量门槛

残差、监测点稳定、质量与能量守恒同时检查。初始内部目标可用质量误差 <1%、能量误差 <5%，明确为待校准工程门槛，不是法定标准。
网格验证比较原始位置指标与排序；单点低速相对误差配合绝对误差。代表案例至少三套网格的系统检查在产品期完成。
物理失败保留日志与场用于诊断，但禁止作为有效推荐。
