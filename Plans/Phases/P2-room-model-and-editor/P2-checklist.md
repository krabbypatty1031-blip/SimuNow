# P2 可验收清单

> 给执行者：按 `P2-01` → `P2-05` 顺序；同层字母可在依赖满足后并行。勾选后把命令与证据写入 `Plans/Delivery/status.md`。

**Goal:** 用户能生成可校验的矩形房间 / 设备 / 座位输入；同一份 JSON 能映射到 P1 管线字段。本阶段不跑求解器、不显示场、不开放计算按钮。

**已有、不得再当 P2 完成证据：** P1 `room_p1.json` 只是求解夹具；P2-01 模型冻结不等于房间编辑器可用。

**锁定（P2 全程沿用）：**

- JSON：Swift Codable camelCase；米制、右手 Z-up
- 不确定值：`value` / `unit` / `source`；可选 `reference` / `uncertainty`
- 设定温度 ≠ 送风温度；循环回风 ≠ 室外新风
- 开口/风口：`s0`/`s1` + `z0`/`z1`，不得默认整墙宽
- 座位 ID 稳定；人物热源与采样点分开
- 缺费用来源不填 0
- 禁止硬编码 Desktop / Downloads 路径
- 没有真实行为的控件保持空状态或明确不可用
- envelope / environment / 扫描几何 / 3D 手柄 / PMV：本阶段不做
