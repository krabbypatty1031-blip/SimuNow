# N6：实测校准与可选扩展

## 目标与前置

前置 N5 可用流程和真实用户反馈。按输入资料与验证收益逐项决定，不把这些研究重新放到所有用户的启动链路。本轮已授权并实现本地测量与有界研究/适配代码；各项仍独立 go/no-go，未用研究结果提升既有物理等级。详见 [实现交接](../Delivery/N5-N6-implementation.md) 与 [子规格/停止条件](../Delivery/N6-research-specifications.md)。真实数据、真机和专业节点验收尚未取得。

## 工作项

| ID | 研究/实现步骤 | 验收与决策门槛 |
|---|---|---|
| N6-01 | 本地 CSV/测量录入：位置、时间、仪表、风档、门窗、功率和单位；匿名化 | 来源与质量明确；缺失/异常/时区处理；不拿主观感受当风速测量 |
| N6-02 | 用有出口流量/速度依据的有限射流模型校准扩散/衰减；独立位置/时段留出验证 | 参数可辨识、误差/适用几何公开；支持单位速度前先过验证；不校准为虚假通用规则 |
| N6-03 | 动态 RC、室外交换/CO2 等各立子规格；热容量/控制/源项和时间步验证 | 解析/守恒例、时间步敏感性、独立数据；平均模型不变逐点预测，湿度/舒适另审 |
| N6-04 | Swift 原生网格实验：压力投影、温度/浮力、边界与 obstacle mask；先 CPU，再考虑 Accelerate/Metal | 公开基准、守恒、分辨率/时间步、内存与耗时；达不到门槛保留研究，不更改首版等级 |
| N6-05 | RoomPlan/手动回退、设备资料/铭牌确认；实测与安装参数结合 | LiDAR 非必需；坐标与来源保留；图像本地；扫描仅几何不能补出热工性能 |
| N6-06 | 按真实需求恢复旧 P1/P3/P4 外部专业复核或机构节点 | 用户单独配置/授权、版本/基准/质量/权限；可选不影响离线规则工具 |

## 研究与产品边界

原生网格不是首版“加一个求解循环”即可完成的增强。先指定 supported boundary、低维或三维、稳态/瞬态、湍流/近壁面范围及基准来源，再计算资源。选择算法与公开数据后才冻结任务工时；当前不承诺具体模型或误差。

测量数据用于校准与独立验证分别分割；保留超范围行为和失败证据。N6-02 得到某台设备/房间有效模型，不等于所有家庭或教室可用。原生/外部求解结果使用新方法版本，不重标已有预览。

舒适模型、年度电费/收益、配置设备报价、自动控制和多房间都需新增明确范围，不能跟随任何 N6 项默认启用。

## 审视与停止条件

输入不可辨识、独立验证不支持或设备预算不满足时停在现有规则/估算工具，说明原因。外部引擎路线可恢复研发工作，但不要求消费者安装 Linux；恢复前更新状态与 ADR，原有 P1 任务仍按原定义验收。
