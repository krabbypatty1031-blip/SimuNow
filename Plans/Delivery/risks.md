# 风险与处理

| 风险 | 提前验证 | 处理 | Owner |
|---|---|---|---|
| CFD 收敛/耗时 | P1 参数化案例与实测性能 | 支持模板、局部加密、队列/节点 | B |
| 扫描几何不能求解 | P2/P6 几何转换检查 | 保留语义、修正或模板化 | A/B |
| 送风数据不完整 | P1/P3 流量/温度来源 | 实测、范围分析，记录等效 | B/C |
| L1/L2 热源重复 | P3 统一能量清单 | 显潜热与辐射/对流口径 | C |
| 风向变化虚构节电 | P5 检查控制与设定依据 | 新 L1 工况或只报舒适 | C/D |
| 舒适模型越界 | P4 适用性和输入校验 | 未评价状态与补测 | D |
| 旧任务污染方案 | P3 输入快照与乱序测试 | run 归属、hash、新鲜度 | C |
| 两端混用平台 API | P0 起双平台编译 | 平台 adapter 与 capability | A |
| sandbox 与容器桥接 | P3 原型/打包 | helper/companion/私有节点 ADR | A/C |
| 范围过大 | 12h/24h/48h集成门槛 | 核心链路优先，延后外围 | 全队 |
| 房间/照片泄漏 | P2 存储与 P6 分享检查 | 本地、匿名、最小传输 | A/C |
| 代理范围/误差 | P7 留出与边界 | 越界直接计算，L2复核 | B/C |

风险事实与假设分开记录。遇到工具或环境错误先定位其与代码的关系，不改物理规则“消除错误”。
