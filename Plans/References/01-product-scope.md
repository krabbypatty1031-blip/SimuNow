# 产品与范围

## 产品定位

SimuNow 是离线使用的房间空调辅助工具。用户用已有房间和设备信息查看三维布局、送风方向与遮挡，比较风向和活动位置的调整；具备所需数据时，查看热量和电费的粗略估算及其依据。日常使用在 Mac、iPhone、iPad 本机完成。

首个场景沿用已完成的小办公室或教室，先支持矩形房间、盒体家具和一类分体空调；家庭卧室/客厅模板在 N5 增加，不能把办公舒适规则直接用于睡眠或儿童。无需重新开发 P2 编辑器或等待扫描能力。

核心流程：**已有项目/简易建房 → 三维查看 → 调整风向和风档 → 看路径与遮挡 → 复制比较 → 保存建议及假设**。

## 输入与用户负担

| 用户希望得到什么 | 最小输入 | 缺少资料时的行为 |
|---|---|---|
| 查看房间 | 尺寸、家具和关注位置 | 只显示几何，不要求墙体热工信息 |
| 风向预览 | 出风口位置、方向；可选风档 | 使用明确的无量纲展示档案，标记扩散形状为假设 |
| 路径/遮挡提醒 | 上述几何、关注点 | 显示路径相交或遮挡，不能称为实测吹风风险 |
| 用电估算 | 功率或明确功率范围、运行时长 | 未知功率则不计算；铭牌为额定情景，不等于实际平均耗电 |
| 电费估算 | 上述输入、电价及币种来源 | 未知费率则只显示电量，不显示零费用 |
| 热平衡估算 | 户外温度、UA/围护依据、室外交换、显热来源 | 单独提示缺项，不阻断三维和气流预览 |

高级物理字段继续保留、允许未知。来源、假设和覆盖项沿用 P2；用户明确采用的预设只进入分析配置或显式编辑事务，不静默改写真实输入。

## 首版范围

Must：复用房间编辑与项目包；非 AR 三维房间查看；相机/选择；Swift 本地送风路径与家具遮挡；一个基准加两个候选；定性比较与可解释建议；结果方法与过期状态；离线保存重开；双端平台和可访问性验收。

Should：有来源的功率/时间/电价估算；简单热平衡；关键输入情景范围；家庭模板；简洁 PDF 或系统分享。

Later：经独立实测校准的射流速度、动态 RC 热模型、CO2 质量平衡、LiDAR 扫描、设备曲线、原生网格求解、专业外部复核、全年核证。自动设备控制、多房间和云账户不在首版范围。

## 用户故事与验收

1. 不知道 U 值、送风温度或 COP，仍能打开房间并预览风向。
2. 修改角度后能看到路径变化；家具内部无路径，遮挡后的区域标记“未模拟”。
3. 点击关注位置得到规则依据，例如“位于当前假设送风路径内”，而非伪造温度或 PMV。
4. 复制两个候选，改变风向或风档，在同视角比较；旧分析不会覆盖当前方案。
5. 补充实际功率与时长后得到对应时段的电量；仅改变风向不会自动产生节电数字。
6. 断网、没有 Docker/worker 的机器仍可完成上述流程并保存重开。

## 结果承诺

结果按“规则预览”“简化估算”“测量记录”“经验证求解”区分。首版只实现前两项计划中的能力；实测与验证等级不能由视觉效果升级。规则无法识别绕流、回流、浮力或贴壁射流的真实位置，不据此宣称房间整体通风有效。

记录首次建模耗时、完成流程比例、本地更新耗时、峰值内存和用户能否辨认结果依据。性能数字是待测目标；不承诺未经实测的准确率、节能率、满意率或合规结论。
