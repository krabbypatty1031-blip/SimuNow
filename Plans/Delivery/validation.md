# 验证计划

## 证据等级

| 层次 | 验证 | 能证明什么 |
|---|---|---|
| 工程 | Swift 单测、双端构建、实际启动、文档操作 | 功能与平台行为 |
| 契约 | 旧 v2/包兼容、新 request/result schema、缺失/版本 | 输入输出格式与版本处理 |
| 规则 | 几何解析例、旋转/平移、段碰撞、确定性 | 规则实现符合规格；不是现实 CFD 精度 |
| 估算 | 单位、解析热收支、时间/电价积分、缺项 | 简化方法的实现正确性 |
| 用户理解 | 试用者区分预览/情景/实测、完成设置比较 | 表达清楚与使用负担 |
| 现实模型验证（N6） | 校准分割、独立测量、公开基准、误差 | 特定范围内的预测能力 |
| 效果核证（另立） | 改造前后、天气/占用修正、长期数据 | 真实收益或年度结论 |

规则检查通过不能转成 physicalValidation=validated；流线好看不能代替风速测量。原 CFD 验证方案保留在 [历史计划](../Archive/engine-first-2026-10-02/Delivery/validation.md)。

## 逐项验收入口

[92项验收案例](../References/11-native-acceptance-cases.md)给出固定输入、预期结果和执行方式；对应N1–N5的27个任务。实施时先按[共用规范](../References/10-ai-execution-guide.md)规划，再完成本任务指定案例；unit/contract/manual各部分分别记录，不能仅因单测通过标实际设备操作通过。

核心门槛为N1/N2/N3/N5的Must案例；N4的20项为Should，可按已实现方法验收，其余保持notRun。若最低系统/签名/真机条件未取得，明确限制与阻断，不能自动降低验收定义或提升最低系统。

## 每个主线阶段的必要验证

| 阶段 | 必须覆盖 |
|---|---|
| N1 | 新旧契约兼容；方法就绪度不依赖无关缺项；ResolvedInput 独立；hash 覆盖规则/假设；取消/错 run/缓存归属；两端非 AR capability |
| N2 | 坐标往返/方向/尺寸旋转；门窗/家具身份；相机/选择/undo；关闭释放；macOS15/iOS18 显示与14/17回退 |
| N3 | 空盒轴向、薄家具段碰撞、起点非法、旋转等变、同 seed 复现；unknown 不当0；不产生单位速度/T/PMV；任务更新与性能 |
| N4 | 功率/热功率分离、时间/费率分段、UA 单位、循环风不当新风、显/潜热能力；缺项/假设/区间的表现 |
| N5 | 离线无 worker 全流程；保存关闭重开/损坏/未来版本；iOS 实际导出与再开；VoiceOver/字号/深浅色/低动态/键盘/横竖屏 |
| N6 | 对新增模型分别冻结来源/解析/守恒/分辨率/独立实测门槛；不能直接继承规则预览的通过状态 |

## 必须存在的反例

无风量/U/COP 可显示规则预览，但不计算单位速度/完整费用；无方向不能自动朝向房间中心。家具遮挡后的区域未模拟。只改相机不重算，改方向不触发无依据节电。晚完成的基准结果不覆盖当前候选；新 profile/version 使相关缓存失效。

热/电示例中的零项必须明确设置为零，不将 unknown 转零。人工 fixtures 标明仅验证算法，未通过现实精度验证。错误项目仍可按 P2 修复，不通过损坏读取来伪造空白有效项目。

## 性能与试用记录

记录硬件/OS/SDK、对象数、路径数/步数、方法版本、p50/p95、峰值内存、场景帧耗时和取消延迟。N3 初始任务 p95≤200 ms、展示约30 fps、64×128路径预算是内部待测目标。达到目标后不添加无关压力检查；改变规模/设备/实现再追加相关验证。

两端至少各一次用户流程试用：建房→看路径→改设置→比较→保存重开，确认能读懂方法与假设。记录耗时/误解，不生成无统计依据的使用满意率。

## 执行入口与记录

代码实施后依改动选择 `Scripts/check.sh test`、`contracts`、`mac`、`ios`。App 专属 schema 使用 Swift 输出与独立 JSON Schema validator；共享模型变化仍跑跨语言 contracts。Python 是开发验证工具，不是 App 启动依赖。

本轮只有 Plans 文档改动，检查相对链接、任务 ID/依赖、当前/历史边界和 git diff；不运行数值引擎或把已有构建成功写成新功能完成。所有实际证据写 [verification](verification.md)，状态写 [status](status.md)。
