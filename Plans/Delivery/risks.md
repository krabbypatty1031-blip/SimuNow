# 风险与处理

| 风险 | 提前检查 | 处理与任务 |
|---|---|---|
| 预览被误解为真实 CFD | 方法标签、试用者解释、导出截图 | N1/N3/N5；预览无 T/PMV/通风达标，假设可见 |
| 未知输入被隐式预设覆盖 | unknown/来源/编辑事务测试 | N1/N5；分析假设独立解析，用户明确采用 |
| 旧严格门槛阻断简单功能 | 不填 U/COP/天气的流程 | N1-03；按方法就绪度，结构/几何安全仍检查 |
| 碰撞规则虚构绕流 | 薄家具/步长/遮挡反例 | N3-02；段相交、首次碰撞终止、后方未模拟 |
| 粒子/颜色暗示真实速度温度 | 检查单位、动画与图层 | N3-04；无量纲和展示时间分开，静态路径优先 |
| RealityView 最低版本与两端能力 | N1 非 AR spike与14/17回退 | N2；availability、公开 API；不默认提高最低版本 |
| 旧任务/缓存污染方案 | 乱序、连续编辑、profile/version/hash | N1/N3；不可变输入、独立run归属、过期与取消 |
| 额定制冷量被当用电 | 反例和方法输入审视 | N4；热/电功率分离，优先功率时段情景 |
| 风向修改虚构节能 | 同功率/时长不同角度对照 | N4/N5；用电方法不依赖角度，无模型不给改善数字 |
| 粗热量掩盖湿负荷/容量不足 | 缺潜热/SHR/曲线案例 | N4；显热估算清楚限定，不判完整设备选型 |
| 本地计算/实体数量拖慢 UI | 目标设备p95、峰值、关窗释放 | N2/N3；资源上限、合并路径、显式后台执行、静态回退 |
| 项目附件/结果超预算 | 实际包大小、undo/历史复制 | N1/N5；有限历史与路径，原子失败，后续流式存储 |
| 消费者流程仍像工程工具 | 首次/日常使用试用 | N5；常用项先显示、保留高级字段、依据可展开 |
| 规则扩大为全面舒适或年度核证 | 比较/建议/PDF审视 | N5/N6；有限条件线索，独立数据与新工作包后升级 |
| 迁移后的旧计划继续驱动安装 | 开工阅读、任务ID与路线覆盖 | 新README/迁移表/ADR；旧任务归档，不复用编号 |
| 扫描/测量泄漏或校准过拟合 | N6数据流程与留出检查 | 本地匿名化；校准/验证分开，范围外不评价 |

这些是当前路线的工作风险，处理随阶段证据更新。已有外部引擎执行限制仍保留历史事实，但不再阻断 N1–N5。规则、估算、物理验证和效果核证不能混成单一“质量通过”。
